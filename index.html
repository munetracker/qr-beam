How it works

  1. Both devices open this app (sender and receiver copies).
  2. Sender chooses a file and starts animated QR transmission.
  3. Receiver starts the camera and scans the frames.
  4. Once enough frames are collected, the file is reconstructed and downloaded.

Prototype limitation: This starter implements a basic QR-frame transport for small files, not Decimen's advanced fountain-code system. Camera scanning and frame capture depend on browser support. For reliable large-file transfer, a fountain-code encoder/decoder and robust frame protocol would be needed.
